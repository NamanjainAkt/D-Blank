# Mobile Optimization Plan - D-Blanks Landing Page

The goal is to ensure the cyberpunk aesthetic remains high-impact on mobile while significantly improving performance and usability for small-screen users.

## 1. Performance Enhancements (Mobile-Specific)

- **Adaptive Particle Counts**:
    - Update `ParticleField.tsx` to reduce particle density by 50-70% on screens smaller than 768px to save GPU cycles.
- **SVG Filter Simplification**:
    - `CrystalButton.tsx` uses heavy `feTurbulence` filters. These will be simplified or the "electric" effect disabled on mobile to improve frame rates.
- **Smooth Scroll (Lenis) Optimization**:
    - Evaluate and potentially disable Lenis smooth scrolling on touch devices to avoid interference with native momentum scrolling and reduce input lag.

## 2. Responsive Layout & Typography

- **Hero Heading Scaling**:
    - Adjust the `clamp` values in `src/app/(public)/page.tsx` for the main title. 
    - Proposed change: `text-[clamp(2.5rem,10vw,7rem)]` (Current minimum `3.5rem` is too large for 320px screens).
- **Crystal Button Responsiveness**:
    - Add a CSS media query to scale the button (using `transform: scale()`) or reduce its fixed 290px width for screens smaller than 360px to prevent layout overflow.
- **Mobile Spacing Audit**:
    - Reduce large vertical paddings (`py-32`, `py-48`) to more mobile-appropriate values (`py-16`, `py-20`) to improve the "flow" of information on small screens.

## 3. Touch & Interaction Improvements

- **Interactive State Refinement**:
    - In `ChromaGrid.tsx` and `GameCard.tsx`, ensure that hover-triggered overlays (like member handles or game genre badges) are accessible via tap.
- **Touch Target Audit**:
    - Ensure all filter buttons, social icons, and links have a minimum 44px hit area per accessibility guidelines.

## 4. Asset Optimization

- **Next.js Image Implementation**:
    - Audit all `<img>` usages (especially in `GameCard.tsx` and `ChromaGrid.tsx`) and replace them with `<Image />` from `next/image`.
    - Implement the `sizes` attribute (e.g., `(max-width: 768px) 100vw, 33vw`) to serve correctly sized images based on the user's device.

## Proposed File Changes

- `src/components/ui/ParticleField.tsx`: Add adaptive count logic.
- `src/components/ui/CrystalButton.tsx`: Add mobile scaling and filter optimization.
- `src/lib/lenis.ts`: Add touch device detection for smooth scroll.
- `src/app/(public)/page.tsx`: Update typography clamps and section padding.
- `src/components/GameCard.tsx`: Switch to `next/image` and optimize touch targets.
- `src/components/ui/ChromaGrid.tsx`: Switch to `next/image` and optimize for touch.
